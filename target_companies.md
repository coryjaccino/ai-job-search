## How to Use

- **Strategic Angle** — The narrative you lead with when applying or reaching out
- **Contacts** — LinkedIn profiles, HR email, recruiter names you discover
- **Status** — `watching` / `contacted` / `applied` / `rejected` / `interviewing` / `offer`
- **Notes** — Outreach attempts, follow-up reminders, things learned

## Quick Status Legend

| Status | Meaning |
|--------|---------|
| Watching | Monitoring for openings; no action taken yet |
| Contacted | Sent LinkedIn message, email, or application |
| Applied | Submitted formal application |
| Rejected | Received a rejection |
| Interviewing | In active interview process |
| Offer | Received an offer |
